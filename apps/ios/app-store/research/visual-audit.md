# Competitor visual audit

October 31, 2026, US storefront. **Verified:** inspected the public icon and first iPhone screenshot for each of the ten apps below at the exact URLs retained in `competitors.json`. Other screenshots, app previews and historical variants were not inspected. No competitor assets are copied into Schwanki's listing.

| App | Icon / first-screenshot treatment | Implication for Schwanki |
| --- | --- | --- |
| AnkiMobile Flashcards | Blue star symbol; direct app capture with an illustrated example and explanatory UI copy | Show the real review flow, with a larger benefit headline outside the screen |
| Quizlet | White Q on blue; saturated blue benefit heading and flashcard demonstration | Make the flashcard use case legible in the first image |
| Brainscape | Face/brain symbol; dark canvas, bold study claim, social proof and a tilted phone | Use strong contrast; omit unearned social proof |
| RemNote | Blue symbol; pale workspace scene with multiple app surfaces | State the iPhone/web boundary clearly instead of implying the whole workspace is native |
| Mochi | Green tree; quiet white/gray “Study less. Remember more.” treatment and a single phone | An outcome headline can stay short; the goose scene supplies visual character |
| Flashcards Deluxe | Stack of cards on orange; straightforward artwork-and-answer study screen | Preserve readable card content rather than replacing it with a mock interface |
| Memrise | Wordmark on yellow; typography-led conversation/timeframe claim and language flags | Avoid a time-to-fluency promise; highlight the user's own vocabulary |
| Drops | Purple/green droplet; language-learning headline and tilted language-picker UI | Use a coherent strong color, while avoiding built-in-course implications |
| Knowt | Teal character; question-format headline above a quiz screen | Keep each image focused on one action, such as recall/reveal/rate |
| Vaia | White academic symbol on blue; large user-count claim and study UI | Use an honest product benefit in place of an unsupported popularity claim |

**Medium-confidence design decision:** retain Schwanki's existing white notebook paper, navy type, royal blue and yellow highlight, with its approved goose artwork inside actual app captures. Four images tell the sequence: visual vocabulary feed → active recall → import entry → web creation boundary. This is an initial conversion hypothesis, not a measured advantage or evidence that no competing app offers similar features.

The first image shows the revealed Spanish sample; the second shows the existing Japanese sample with its reading and illustration. Both are genuine app captures, not fabricated account content. The import slide adds clearly labeled marketing annotations for supported input routes: Anki exports from Files on iPhone, Google Docs/Sheets connections on the web, and PDF/slide uploads on the web. These surround the real native import entry; they are not fabricated app controls or a screenshot of a completed import. Native import remains conditional on release acceptance. No before/after learning result, user review, fabricated metric or guaranteed learning outcome appears in these assets.
